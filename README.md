# ازبطها · Day Companion

تطبيق مصري ذكي وهادي بيبسطلك يومك ويجاوبك بوضوح على سؤال: **إيه اللي ورايا؟**

---

## 🚀 خطوات بناء تطبيق الأندرويد (APK):

1. **تثبيت الاعتمادات:**
   ```bash
   npm install
   ```

2. **بناء المشروع ودمجه مع أندرويد تلقائياً:**
   ```bash
   npm run build:android
   ```
   *(الأمر ده بيبني تطبيق الويب عبر Vite وبيعمل مزامنة Capacitor Sync لمشروع الأندرويد).*

3. **فتح المشروع في Android Studio:**
   ```bash
   npx cap open android
   ```

4. **استخراج ملف الـ APK:**
   - استنّى Gradle يخلص المزامنة والتحميل.
   - من القائمة العلوية اختر: **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
   - بعد انتهاء البناء، هيظهر إشعار نجاح، اضغط على **locate** للوصول لملف `app-debug.apk`.

## 🔔 دليل اختبار موثوقية التنبيهات على الجهاز الحقيقي:

للتأكد من أن الإشعارات الصوتية والمواعيد ترن في موعدها بدون تأخير على جميع أجهزة أندرويد (Samsung / Xiaomi / Oppo / Realme):

### (أ) أذونات الإشعارات والمنبّه الدقيق (Exact Alarms):
- عند فتح التطبيق لأول مرة، اضغط **"تمام، فعّل"** لمنح إذن الإشعارات.
- على أندرويد 12+ (Android 12/13/14+)، تأكد من منح إذن **"المنبّهات والتذكيرات / SCHEDULE_EXACT_ALARM"** من خلال زر التفعيل في شاشة التنبيهات.

### (ب) تجربة موعد بعد 3 دقائق مع إغلاق التطبيق تماماً:
1. افتح التطبيق وأضف موعداً جديداً بوقته بعد 3 دقائق من الوقت الحالي.
2. اخرج من التطبيق واغلقه تماماً من شاشة التطبيقات المفتوحة مؤخراً (Swipe away / Force close).
3. انتظر حلول الوقت وتأكد من ظهور الإشعار مع الصوت المخصص `azbotha_notification.ogg`.

### (ج) تجربة قفل الشاشة والوضع الساكن (Doze Mode):
1. أضف موعداً بعد 5 دقائق.
2. اقفل شاشة الهاتف تماماً واتركه على الطاولة.
3. تأكد من إيقاظ الشاشة أو ظهور الإشعار الصوتي في الدقيقة المحددة.

### (د) إعادة تشغيل الهاتف (Device Reboot):
1. أضف موعداً لليوم التالي أو بعد ساعة.
2. قم بعمل **Restart / إعادة تشغيل** للهاتف بالكامل.
3. تأكد أن المنبّهات المجدولة تستمر في الرنين بالموعد دون الحاجة لفتح التطبيق يدوياً.

### (هـ) تغيير التوقيت / المنطقة الزمنية:
- في حال السفر أو تغيير المنطقة الزمنية للجهاز، يقوم التطبيق تلقائياً بإعادة حساب أوقات التنبيهات وفق التوقيت المحلي الجديد للمستخدم.
